# 7 分钟课堂展示方案

## 展示前准备

1. 保留项目 `.deps`，运行 `open build/MathSolver.app`，等待公式预览加载。
2. 窗口放大，打开 README 备用；提前运行 CTest，确认本地离线资源完整。
3. 将求根精度设为 10^(-8)、最大迭代 100，积分分割数设为 100。
4. 图形默认范围 x∈[-5,5]、y∈[-3,3]。准备 CSV 和 PNG 导出位置。

## 时间安排

| 时间 | 内容与现场操作 | 讲解要点 |

| 0:00–0:40 | 打开主界面，输入公式 | 全 C++ 数学计算；KaTeX 只排版；三个区域各司其职 |

| 2:20–3:40 | 二分法与 Newton | 连续性前提、切线迭代、误差指标与失败情形 |
| 3:40–4:50 | 三类数值积分 | Riemann 和到梯形与抛物线近似；比较分割数 |

## 可现场操作的例子

### 例 1：标准极限

“极限计算”输入 `\frac{\sin x}{x}`，点 0，双侧。输出规则判定 1。解释这来自标准极限，有限采样只能辅助观察。

### 例 2：左右极限不一致

输入 `\frac1x`，点 0。双侧显示不存在；切换右侧显示 +∞；左侧显示 −∞。强调正负无穷不是有限实数结果。

### 例 3：符号导数与切线

“导数与切线”输入 `x^3+\sin x`，阶数 1，点 0。导函数等价于 `3x²+cos x`，指定点导数 1，切线 y=x。显示原函数、导函数和切线。可将点改为 1，观察切线改变。

### 例 4：两种求根法比较

“方程求根”输入 `x^2-2`，区间 [0,2]，选择二分法；结果约 1.41421356。查看误差指标趋势。改为 Newton 法，初值 1，再计算并比较迭代次数。随后输入 `x^2+1`、初值 0，显示导数为零，说明算法不总成功。

### 例 5：数值积分与误差

“积分计算”输入 `x^2`，上下限 0、1，分割数 100。依次选择矩形、梯形、Simpson 法，与理论值 1/3 比较。在“数值算法实验”中查看填色与不同分割数的结果。选择符号不定积分得到 `x³/3+C`。强调 Simpson 对此多项式精确，不能推广到所有函数。

### 例 6：Taylor 近似

“Taylor 展开”输入 `e^x`，展开点 0，阶数 4。结果等价于 `1+x+x²/2+x³/6+x⁴/24`。将 x 范围设置 [-2,2]、y 范围 [-1,8] 并应用，比较两条曲线。解释局部近似和余项。

### 例 7：多函数与间断点

“函数绘图”分三行输入 `\sin x`、`\cos x`、`1/x`。拖动平移、滚轮缩放。说明常见极点会断线，但有限采样不保证识别所有间断。导出 PNG。

### 例 8：错误输入与能力边界

输入不完整 `\frac`，展示中文位置提示。再输入 `\sin(1/x)` 求 x→0 极限，显示“暂不支持精确判定/数值观察”。最后尝试对 `\sin(x^2)` 选择符号积分，展示明确的不支持提示，再切换数值积分。

## 建议收尾用语

这个项目把课本中的数学定义和定理转化为可运行的 C++ 算法。我学到了表达式树、符号规则、迭代误差与 GUI 分层，也认识到计算结果必须说明适用条件。后续将优先完善精确系数、误差界和更多经过验证的数学规则。
