## 实现变化

- `\sec`、`\csc`、`\cot` 降低为保留分母的等价 AST，复用求导、积分、绘图及定义域检查。
- `\arccot x = \pi/2-\arctan x`，采用实数主值区间 `(0,pi)`；补齐渲染宏。
- 支持 `\log_3 x`、`\log_{3} x`、`\log_3^2 x`、`\lg x`、`\dfrac`、`\tfrac`；默认 `\log` 仍为常用对数。
- 保留高次幂结构，避免展开后在结果回读求值时出现灾难性相消。
- 偶次根在原实数定义域内转换为有理指数；奇次根仍保留负数实根语义。
- 积分增加反向链式法则结构换元、`t=e^x`、`t=tan(x/2)` 有理式换元，以及 `P(x)/sqrt(A+B*x^2)` 的递推。它们按表达式结构工作，不匹配题目字符串。
- 对数原函数保留实数绝对值分支，例如 `1/(x ln x)` 在 `0<x<1` 与 `x>1` 的连续区间均可使用 `ln|ln x|+C`。
- 拒绝未能完成符号验证或足够实数点验证的候选原函数。抽查通过仍明确标为抽查，不能当作恒等证明。
- 三角区间包围同时检查端点、极值和零点；正常区间可积分，跨极点区间拒绝。

## 全书逐章范围与缺口

| 教材内容 | 当前状态 |
|---|---|
| 第1章：集合、函数、实数完备性 | 支持有限范围实函数表达式；没有集合运算、完备性证明或自动解文字题。 |
| 第2章：极限与连续 | 部分函数极限已有严格规则和回归；一般数列极限、递推数列、分段函数、含参数连续性和证明题未覆盖。 |
| 第3章：导数与微分 | 显式单变量初等函数为重点；自由参数a、n，未知函数f/g，隐函数、参数方程、相关变化率和分段点判定尚未支持。高阶最多8阶，不能替代任意n阶通项。 |
| 第4章：中值定理及导数应用 | 部分洛必达/Taylor计算可用；自动证明、完整单调区间与最值分析、曲率尚未形成完整解题模块。 |
| 第5章：积分 | 已验证本轮71题；一般换元/分部/有理式仍非完备算法。反常积分、收敛性证明、Gamma函数及含自由参数积分未支持。上下限/趋近点界面仍为数值参数，不能把输入小数近似pi/2当作精确pi/2。 |
| 第6章：积分应用 | 可以计算用户自行列出的部分正常定积分；不能从题目自动建立面积、体积、弧长、功等数学模型。 |
| 第7章：空间解析几何与向量 | 不在当前一元微积分产品范围内，未实现。 |

下一轮仍需扩展并逐题验证以上缺口，特别是：精确符号参数/端点、含参数计算、分段/隐式/参数函数、广义积分。不能以本轮测试通过声称“整本书上的题没问题”。
