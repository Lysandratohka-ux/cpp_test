## 新增数学能力

### 混合根式原函数

对同一线性表达式 u=ax+b 的整次数根式，选根次数的最小公倍数 N（不超过12），以 t=u^(1/N) 消除根式，x=(t^N-b)/a，连同 Jacobian 转成有理函数积分，再换回原变量。仅在转换后确为有理式且求导验证通过时返回。

例如：

```latex
\frac{1}{\sqrt{x}+\sqrt[3]{x}}
\frac{\sqrt{x}}{1+\sqrt[3]{x}}
\frac{1}{\sqrt{2x+1}+\sqrt[3]{2x+1}}
\frac{1}{\sqrt[3]{x}+\sqrt[4]{x}}
```

对旧版源码编译对照，以上四类原函数均原先返回无法求出，新版可求。旧版对照记录：`verification/infinity/baseline-probe.log`。共同定义域的连续区间限制仍适用；本轮这些原函数仅通过符号求导后的数值抽查，界面明确说明未完成全定义域恒等证明。额外测试在不同于引擎抽查的点再次验证结果 LaTeX 求导值。

### 复合幂函数极限

先证明底数趋于1，再使用 ln(1+u)~u，将幂函数转换为指数乘以底数增量的极限；以原来的解析展开/通分规则求出指数极限，最后以指数函数的连续性还原。允许底数本身存在可去奇点。若底数为正的解析函数，也可直接取对数。保留原指数的定义域，未确认时返回无法判定。

| 输入，x→0 | 结果 |
| --- | --- |
| `((e^x-1)/x)^{1/x}` | e^(1/2) |
| `((\sin x)/x)^{1/x^2}` | e^(-1/6) |
| `(2(1-\cos x)/x^2)^{1/x^2}` | e^(-1/12) |
| `(1+x^2)^{1/x^3}` | 右侧+∞、左侧0，双侧不存在 |
| `1^{\ln(-x)}`，右侧 | 无法判定，不抹去实数定义域限制 |

不会以采样宣布极限存在，亦不保证解决所有幂函数或振荡极限。

### 多项式化简

展开括号、合并同类项、精确有理数系数；最高64次。以安全 AST 限制语法，再由符号引擎展开，并检查新旧式之差恒等为零。精确非整数指数不因浮点舍入而放行。变量分母、三角函数等不属于该工具的输入范围，给出中文提示，不声称做通用有理式化简。

例：`(x+1)^4-(x-1)^4` 得 `8x^3+8x`。

## 验证与平台

完整测试记录：`infinity-2.3-tests.log`；最后的模式高亮调整经 `infinity-2.3-gui-final.log` 复验；界面截图：`verification/infinity/`。

- 原有核心64项断言，微积分求导46、积分53、极限33、解析9项断言。
- 原有教材求导24、积分74、极限11、语法与定义域21项用例。
- 新增积分6组（30项断言）、极限14组（22项断言）、多项式16组（44项断言，含9组拒绝输入）。数量以测试日志为准。
- GUI保持原26条计算流程，新增多项式、混合根式积分、复合底数极限三条流程；另测空白启动、首页按钮、历史窗口、教学、8条曲线、鼠标切线、间断/尖点拒绝、缩放和平移等。
- 13/13测试通过；最终GUI复验1/1通过，独立Bundle移至临时目录并清空开发路径后启动测试退出0，最终深度签名校验通过。
- macOS Apple Silicon 实际编译、启动、截图和打包；Windows的 Qt 界面、ICO及原生C++符号辅助进程协议同步更新，尚未在 Windows 主机实测，不提供声称已验证的 EXE。

新图标资源可由 `tools/icons.cpp` 生成，随后在 macOS 运行 `iconutil -c icns resources/icons/Infinity.iconset -o resources/icons/Infinity.icns`。项目仍使用 C++20、Qt、libqalculate 和本地 KaTeX，不增加依赖许可证。

已知限制：不保证覆盖整本教材；反常积分仍不支持；新的根式算法面向不定积分，定积分仍以已有符号规则或正常定积分数值后备处理；根次数最小公倍数超过12、非有理换元、某些特殊函数/复杂定义域仍可能无法求解。
