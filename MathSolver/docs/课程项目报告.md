# MathSolver：基于 C++ 表达式树的高等数学计算与算法实验软件

课程：高等数学（上）  
开发环境：Apple Silicon macOS，Apple Clang 21，C++20，CMake 4.4.3，Qt 6.11.2  
项目性质：面向单变量实函数的有限符号计算与数值算法教学实践

## 1. 研究背景与开发目标

高等数学中的极限、导数、积分和方程求根既包含严格的数学定义，也包含可实施的近似计算。纸笔推导有利于理解理论，计算机实验则可以直观展示迭代过程和误差变化。本项目将二者结合：用户输入 LaTeX 表达式，程序构建数学表达式树，再执行符号规则或数值算法，最后以公式、曲线、表格和误差趋势展示结果。

开发目标包括：理解编译器前端的基本思想；使用现代 C++ 和智能指针管理数学对象；将数学算法从 GUI 分离；用自动化测试验证恒等式与误差；区分可证明的数学结论和有限精度的数值观察。项目没有尝试实现通用计算机代数系统，也不把复杂数学运算交给在线服务。

## 2. 软件功能与系统结构

桌面应用采用左导航、中央输入和参数、右结果与图像的三栏布局。提供极限、导数、积分、求根、Taylor、函数绘图和数值实验七个入口，支持本地公式预览、模板、计算历史、结果复制、PNG/CSV 导出及深浅主题。

数学核心库为纯标准 C++。表达式节点由 `shared_ptr<const Node>` 共享，构建后不可变，便于线程任务安全共享原函数和导函数。Qt Concurrent 在后台执行数学计算，主线程负责读取输入快照和呈现结果。Qt Painter 完成图形绘制，WebEngine 中的 JavaScript 只调用本地 KaTeX 排版。

三层之间的关系为：LaTeX 字符串 → Token → AST → 符号/数值算法 → 结构化结果 → Qt GUI。KaTeX 排版路径与数学计算路径分别存在，互不替代。

## 3. LaTeX 表达式解析原理

词法分析器识别数字、变量、运算符、括号和白名单命令。例如 `\frac{\sin x}{x}` 转换为分式、分组、正弦、变量等 Token。未知命令、错误数字和多余括号会返回带位置的中文错误。位置按 UTF-8 字节计数。

递归下降解析器按以下优先级组织：加减最低，乘除和隐式乘法其次，一元正负号低于乘幂，幂右结合，原子表达式最高。因此 `-x^2` 表示 `-(x^2)`，`2^3^2` 表示 `2^(3^2)`。隐式乘法使 `2x` 与 `3\sin x` 可直接输入。

分式生成除法节点，根式生成带次数的 root 节点，函数生成一元节点。数值求值递归遍历 AST，通过受控的 `std::sin`、`std::pow` 等函数计算。程序不使用 `eval`、脚本解释器或用户代码执行。

为保护原函数定义域，解析阶段不将 `0*ln(x)` 等表达式化为常数零；符号变换阶段采用局部化简，结果仍需按原函数定义域解释。输入长度、嵌套深度、符号递归工作量和阶数均有限制。

## 4. 二分法与零点定理

设 f 在闭区间 [a,b] 连续，且 f(a)f(b)<0。由零点定理，区间内至少存在一个零点。取中点 m=(a+b)/2，根据 f(m) 与端点函数值的符号，保留仍异号的半区间。重复 n 次后，保留区间长度为初始长度的 2^(-n)，其中点与某个被保留根的距离不超过区间半宽。

实现时比较符号位，避免直接计算 f(a)f(b) 溢出。程序同时检查区间半宽和残差，遇到非有限函数值直接停止。区间运算对分母包含零、对数非正参数等情况进行保守拒绝。例如 `1/x` 在 [-1,1] 两端异号，却不连续，不能据此使用零点定理。区间检查是浮点保守检查而非形式化证明；用户仍需理解连续性前提。

二分法的优势是条件满足时稳健，缺点是线性收敛，且不能凭异号区间保证零点唯一。

## 5. Newton 法的导数推导

在当前近似 x_n 处以切线近似函数：

f(x) ≈ f(x_n) + f'(x_n)(x−x_n)。

令切线与 x 轴相交，得到

x_(n+1) = x_n − f(x_n)/f'(x_n)。

导数由 AST 规则生成。例如乘积法则 `(uv)'=u'v+uv'`，商法则 `(u/v)'=(u'v−uv')/v²`，复合函数使用链式法则。一般正底数幂 `u^v` 的导数写为 `u^v[v'ln(u)+vu'/u]`；常数幂单独处理，以便正确支持负数自变量的整数次幂。

若根附近函数足够光滑、导数不为零且初值足够接近，Newton 法通常表现出二次收敛。实际程序必须处理导数接近零、越出定义域、溢出、循环或超限。软件记录每一步 x、f(x) 和相邻差；相邻差仅为停止指标，不能普遍视为严格根误差界。

## 6. 数值积分与定积分定义

将 [a,b] 等分为 n 份，h=(b−a)/n。中点矩形法使用每小段中点值乘以 h 并求和，是 Riemann 和的具体形式。梯形法将每小段内函数近似为直线，得到

T_n = h[(f(a)+f(b))/2 + Σ f(a+ih)]。

复合 Simpson 法用每两小段上的二次插值替代原函数，要求 n 为偶数：

S_n = h/3 [f(a)+f(b)+4Σ奇数节点 f_i+2Σ内部偶数节点 f_i]。

当相应导数连续且有界时，中点矩形法和梯形法的全局误差通常为 O(h²)，Simpson 法为 O(h⁴)。软件展示不同分割数的结果和相邻差；没有提供导数上界时，不把相邻差称为严格误差界。

符号定积分使用原函数 F 的差 F(b)−F(a)，其前提是区间内满足微积分基本定理的条件。本版本对区间定义域做保守检查，不支持跨越奇点的反常积分。

## 7. 软件实验与误差分析

实验源代码为 `examples/experiments.cpp`，运行 `build/mathsolver_experiments` 可以重新生成 `experiment-results.csv`。以下数据来自本机 C++ 实际执行，参考值分别为 1/3 和标准库的 sqrt(2)。

对 f(x)=x² 在 [0,1] 上积分：

| 方法 | n=4 绝对误差 | n=8 绝对误差 | n=16 绝对误差 | n=32 绝对误差 |
|---|---:|---:|---:|---:|
| 中点矩形 | 0.00520833333 | 0.00130208333 | 0.000325520833 | 0.0000813802083 |
| 梯形 | 0.0104166667 | 0.00260416667 | 0.000651041667 | 0.000162760417 |
| Simpson | 0（本次浮点结果） | 0 | 0 | 0 |

分割数翻倍后，前两种方法的误差约缩小至四分之一，与二阶收敛相符。Simpson 对二次多项式理论上精确，本例也不能据此声称其对所有函数无误差。浮点输出恰为零只是该实验的数值现象。

对 f(x)=x²−2，取正根区间 [0,2]、Newton 初值 1、精度 10^(-10)：二分法使用 36 步，根约为 1.4142135623551，参考误差约 1.80×10^(-11)。Newton 法按残差与迭代差双重停止条件运行，完整数据见 CSV；更少的迭代体现局部快速收敛，不能代替其前提条件。

Taylor 实验取 e^x 在 0 点的四阶多项式 `1+x+x²/2+x³/6+x⁴/24`。在 x=1 时多项式值为 2.7083333333333，与 e 的差约为 0.00994849513；在更靠近展开点的位置，误差更小。该现象来自余项中的高次幂，不代表任意函数都可在全实轴由 Taylor 级数表示。

极限实验分别输入 `sin(x)/x`、`1/x` 和 `sin(1/x)`，观察标准极限规则、左右无穷不一致以及无法由采样严格判定的区别。程序没有把振荡函数的少量采样结果直接判为极限。

测试使用数值恒等式验证导数及原函数，例如多个点比较 `(x³+sin x)'` 与 `3x²+cos x`，并以中心差分交叉检查多类复合函数。错误输入、定义域、最大迭代次数和奇数 Simpson 分割数也有测试。具体执行状态见阶段记录。

## 8. 已实现功能、局限与后续方向

已实现安全解析、离线公式显示、单变量求值、多函数绘图、符号求导、高阶导数、有限符号积分、三类数值积分、二分与 Newton、Taylor 和有限极限规则，并提供历史和导出功能。

局限主要来自数学范围与数值精度：不是完整 LaTeX 解析器；不是通用符号积分或极限引擎；double 系数不是精确有理数；图形采样不能识别所有间断；定义域区间检查可能过度保守；Taylor 无自动余项界；未实现任意多项式的精确求根。特别复杂的表达式可能被资源限制拒绝。GUI 数学任务在后台线程中执行，但仍没有交互式取消功能。

后续可以增加有理数系数类型、AST 公共子表达式消除与求导缓存、更多带前提条件的符号规则、可证明的误差估计以及独立安装包。扩展时应保持已有算法可编译、可测试和可解释，避免以硬编码示例替代一般计算。
