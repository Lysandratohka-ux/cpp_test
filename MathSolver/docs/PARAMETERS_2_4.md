# Infinity 2.4：带字母参数的积分与极限

计算变量仍为 `x`。可直接输入实数常量参数 `a、b、c、n`，不必赋值；`n` 不自动假定为整数。LaTeX 命令和变量均有白名单，不将输入直接交给 CAS 的自由语言或执行器。

## 直接操作

在计算器中切换相应模式，输入表达式后计算。模板下拉框新增带参数的例子。

| 表达式 | 设置 | 结果/条件 |
| --- | --- | --- |
| `\sin(ax)/x` | 极限，x→0，双侧 | a，任意实数a，包含a=0 |
| `(e^{ax}-1-ax)/x^2` | 极限，x→0 | a²/2 |
| `(\sin(ax)-ax)/x^3` | 极限，x→0 | −a³/6 |
| `\sin(ax)/\sin(bx)` | 极限，x→0 | a/b，b≠0；b=0时原式无定义 |
| `(ax^2+b)/(cx^2+1)` | 极限，x→inf或−inf | a/c，c≠0；c=0的退化分支暂未覆盖 |
| `x^a` | 不定积分 | x^(a+1)/(a+1)+C（a≠−1），ln(x)+C（a=−1）；x>0 |
| `a*x^2+b*x+c` | 不定积分 | ax³/3+bx²/2+cx+C |
| `\sin(ax)` | 不定积分 | −cos(ax)/a+C（a≠0），C（a=0） |
| `e^{ax}` | 不定积分 | e^(ax)/a+C（a≠0），x+C（a=0） |
| `e^{ax}` | 定积分，0到1 | (e^a−1)/a（a≠0），1（a=0） |
| `x^a` | 定积分，1到2 | (2^(a+1)−1)/(a+1)（a≠−1），ln2（a=−1） |
| `x^a` | 极限，x→0，右侧 | a>0为0；a=0为1；a<0为+∞ |

参数条件直接排版在结果中，能够复制完整 LaTeX。历史记录保留原始表达式、参数设置和结果。

`\sin ax` 也按隐式乘积参数解析为 `\sin(a*x)`；仍建议显式括号，特别是多个函数相乘时。参数写普通字母 `a`，不要写不存在的命令 `\a`。

## 数学规则与验证

1. 参数采用独立的 AST 叶节点，与 x 区分；进入 CAS 时映射到应用专用的实数未知变量，防止与库里的单位/内置常量混淆。没有用固定几个参数值代替符号计算。
2. 参数原函数必须通过关于 x 的符号求导恒等验证；失败时返回无法求解，不借助采样把结果认证为通式。纯实数幂规则在 x>0 上单独保留指数−1分支。常见单参数的零值退化分支由原式代入参数0后重新积分、求导验证生成，不是对演示输入字符串特判。
3. 收集原式和候选原函数的分母非零、实数幂正底数、对数及根式域条件。不能安全推断全部参数分支时，明确输出条件下的结果；不在条件之外套用。
4. 有限点的参数极限先把解析组合通分，逐项确认局部实解析条件以及各原始除数在去心邻域非零，再比较最高12阶 Taylor 系数。分母首项含参数时加上非零条件；分子首项为0等退化情况不会靠取样猜测。无穷处的部分有理式以 x=1/t 转到局部展开。
5. 数值绘图、求根、求导与数值积分目前要求先将参数替换成具体数值。未绑定参数的数值求值会明确抛出错误；参数不会默认为0。带参数计算不向绘图器传入无法求值的曲线。

## 本轮范围与限制

- 带参数的正常定积分目前覆盖可确认整段定义域的多项式、sin/cos/exp组合、常数分母，以及上下限都大于0的实数幂。上下限和趋近点仍填数字或 inf，尚非符号边界。
- 不支持自由多变量函数、参数取值约束编辑器、自动推断n为整数、完整分段函数或自动穷尽所有多参数退化分支。
- `a/x` 在0处依赖a的符号，`sin(a/x)`依赖振荡退化；当前保守返回无法判定。一般含参数幂在0处的双侧极限不等同于右极限，须留意实数定义域。
- 不支持反常积分，因此带任意实数指数的 `x^a` 从0到1暂时拒绝；不能仅因部分参数范围收敛就无条件返回1/(a+1)。
- 通用特殊函数原函数还可能因定义域或恒等验证不充分而被拒绝。条件公式不保证可以整段粘回表达式编辑器计算；它们属于结果 LaTeX。
