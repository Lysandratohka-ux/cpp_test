# 阶段记录

记录日期：2026-10-30（Asia/Shanghai）。原目录为 C++ 练习仓库；未发现需要迁移的 Python MathSolver。项目单独放在 `MathSolver/`，保留既有练习文件。

## 阶段一：可运行 MVP

完成 CMake/C++20 工程、独立数学核心、Qt 三栏主窗口、中文导航、离线 KaTeX、白名单 Tokenizer 与递归下降解析、数值求值、多函数曲线、二分法、Newton 法和符号求导。

环境检查得到 Apple Clang 21.0.0（arm64）与 CMake 4.4.3。系统起初没有可用 Qt，通过项目本地 micromamba 安装原生 Qt 6.11.2 Widgets/Concurrent/WebEngine，未引入 Python 运行时。首次核心库构建修复了混合 auto 声明错误后通过 58 项检查。

限制：单变量、有限语法、double 算术；不执行用户输入代码。

## 阶段二：微积分与算法扩展

完成常见连续性/标准极限和有理函数规则、有限符号积分、正常定积分、中点矩形/梯形/Simpson、1～8 阶导数、Taylor、多函数对比、误差指标图与算法示意。使用区间算术保守检查定义域，拒绝跨越 `1/x` 奇点的区间。

补充负数奇次根求导、源表达式定义域保留、Simpson 偶数分割、非法区间、未收敛与导数为零等边界检查。最终核心测试为 **64 项检查**。Newton 的停止条件已改为初值可按残差直接通过，后续迭代同时要求残差和步长达标。精度 10^(-10) 时，示例二分法 36 步，Newton 5 步。

限制：没有通用符号积分/极限、严格通用误差界、任意精度系数、多项式精确求根或反常积分。数值观察明确标注，不能当作极限证明；区间检查可能过度拒绝合法表达式。

## 阶段三：产品体验与课程交付

完成模板、最近 50 条本地历史、复制、PNG/CSV 导出、深浅界面、滚轮缩放与平移；数学任务使用后台线程，公式预览输入防抖；源码经过 clang-format 排版并补充关键算法注释。

提供完整 README、课程项目报告、7 分钟课堂展示方案（八组现场例子）、可运行 C++ 实验程序与实际 CSV 数据，保存依赖包清单和第三方许可证。

完整 GUI 已编译并在 macOS 桌面真实运行。早期 GUI 测试在受限沙箱内因 WindowServer/系统进程访问超时，转为正常桌面权限运行。最终测试包含：

1. 纯 C++ 核心测试：64 项检查。
2. Qt GUI 冒烟测试：十组计算，覆盖七个导航模块、正常结果和跨奇点积分错误；检查输入公式与结果公式实际存在 KaTeX 渲染 DOM，并输出窗口截图 `build/gui-smoke.png`。
3. 实验程序：实际计算矩形/梯形/Simpson 误差及二分/Newton 根误差，结果在 `docs/experiment-results.csv`。

最终 CTest 状态以 `docs/ctest.log` 为准，截图在 `docs/界面预览.png`。

交付限制：当前 `.app` 为本机动态链接开发构建，依赖同目录下 `.deps/qt`；不是经过签名、公证和完整独立部署的跨机器安装包。没有后台任务取消按钮。图形和公式画布保持深色，深浅切换作用于主要控件。所有尚未支持的数学能力均明确返回错误或数值观察，无硬编码演示结果。
